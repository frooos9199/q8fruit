# 📱 تطبيق فكهاني الكويت - React Native

تطبيق موبايل لمتجر الفواكه والخضار مع نظام نوتيفيكيشن متكامل.

## 🚀 المميزات

- ✅ واجهة عربية كاملة
- ✅ تصفح المنتجات مع الصور
- ✅ سلة مشتريات ذكية
- ✅ طلب سريع (اسم + رقم موبايل)
- ✅ نوتيفيكيشن للطلبات الجديدة
- ✅ دعم iOS و Android
- ✅ مزامنة مع Firebase

## 📦 التقنيات المستخدمة

- React Native + Expo
- TypeScript
- Firebase (Firestore + Cloud Messaging)
- React Navigation
- Expo Notifications

## 🔧 تشغيل التطبيق

### 1. تنصيب المكتبات
```bash
cd mobile-app
npm install
```

### 2. إعداد Firebase
1. انسخ إعدادات Firebase من الويب
2. عدّل ملف `src/services/firebase.ts`

### 3. تشغيل التطبيق
```bash
# تشغيل عام
npm start

# Android
npm run android

# iOS
npm run ios
```

## 📱 الشاشات المتاحة

1. **تسجيل الدخول** - دخول سريع أو كزائر
2. **الرئيسية** - عرض المنتجات مع البحث
3. **السلة** - إدارة المشتريات والطلب
4. **طلباتي** - متابعة الطلبات (قريباً)
5. **حسابي** - الملف الشخصي (قريباً)
