# 🍎 فكهاني الكويت - Q8 Fruit

منصة متكاملة لبيع الفواكه والخضار الطازجة في الكويت

## 📱 المشروع

يحتوي هذا المستودع على:
- 🌐 **الموقع الإلكتروني** (Next.js)
- 📱 **تطبيق الجوال** (React Native)

## 🚀 الموقع الإلكتروني

### التشغيل المحلي:
```bash
npm install
npm run dev
```

### البناء للإنتاج:
```bash
npm run build
npm start
```

## 📱 تطبيق الجوال

### الأوامر:
```bash
cd mobile-app-rn
npm install
npm run android  # لتشغيل على أندرويد
npm run ios      # لتشغيل على iOS
```

### المتطلبات:
- Node.js 20+
- Xcode (لـ iOS)
- Android Studio (لـ Android)

## 🔥 التقنيات المستخدمة
