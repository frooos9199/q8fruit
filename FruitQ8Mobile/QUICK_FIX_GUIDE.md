# 🔧 دليل الإصلاحات السريع

## ✅ تم إصلاح مشكلة الكراش عند تغيير صورة المنتج

### 📋 الملفات المعدلة:
1. ✅ `src/services/firebase.ts` - تحسين رفع الصور ومعالجة الأخطاء
2. ✅ `src/screens/AddEditProductScreen.tsx` - تحسين اختيار الصور
3. ✅ `android/app/src/main/AndroidManifest.xml` - إضافة الصلاحيات

### 🚀 خطوات تطبيق الإصلاحات:

#### الطريقة السريعة:
```bash
cd FruitQ8Mobile
./rebuild.sh
npm run android
```

#### الطريقة اليدوية:
```bash
cd FruitQ8Mobile

# 1. تنظيف cache
npm run clean:metro
npm run kill-metro

# 2. تنظيف Android build
cd android
./gradlew clean
cd ..

# 3. إعادة البناء والتشغيل
npm run android
```

### 🔍 التحقق من الإصلاح:
1. افتح التطبيق
2. سجل دخول كمسؤول (admin@fruitq8.com)
3. اذهب إلى "إدارة المنتجات"
4. اختر منتج للتعديل
5. غير الصورة
6. اضغط "حفظ"
7. ✅ يجب أن يعمل بدون crash

### 📊 التحسينات المطبقة:

#### 1. تحسين جودة الصور:
- الجودة: 80% → 60%
- الحد الأقصى: 1024x1024 بكسل
- عدد الصور: 10 → 5 صور

#### 2. معالجة الأخطاء:
- ✅ التحقق من صلاحية URI
- ✅ معالجة أخطاء الرفع
- ✅ رسائل خطأ واضحة
- ✅ الاحتفاظ بالصور القديمة عند الفشل

#### 3. الصلاحيات:
- ✅ CAMERA
- ✅ READ_EXTERNAL_STORAGE
- ✅ WRITE_EXTERNAL_STORAGE
- ✅ READ_MEDIA_IMAGES

#### 4. تحسين الذاكرة:
- ✅ largeHeap="true"
- ✅ hardwareAccelerated="true"

### 🐛 في حالة استمرار المشكلة:

#### 1. تحقق من Logs:
```bash
npx react-native log-android
```

#### 2. تحقق من الصلاحيات:
- إعدادات الجهاز → التطبيقات → FruitQ8
- تأكد من منح صلاحيات الكاميرا والصور

#### 3. إعادة تثبيت التطبيق:
```bash
cd android
./gradlew clean
cd ..
npm run android
```

#### 4. تحقق من حجم الصور:
- استخدم صور أصغر من 5MB
- تجنب الصور عالية الدقة جداً

### 📝 ملاحظات مهمة:
- يجب إعادة بناء التطبيق بعد التعديلات
- تأكد من منح الصلاحيات في إعدادات الجهاز
- الصور يتم ضغطها تلقائياً لتحسين الأداء
- في حالة فشل رفع صورة، يتم الاحتفاظ بالصورة القديمة
