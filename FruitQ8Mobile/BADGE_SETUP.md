# 🔔 إعداد Badge على أيقونة التطبيق

## 📱 iOS

### الخطوة 1: تثبيت المكتبة
```bash
npm install @react-native-community/push-notification-ios
cd ios && pod install && cd ..
```

### الخطوة 2: إضافة الأذونات في Info.plist
افتح `ios/FruitQ8Mobile/Info.plist` وأضف:
```xml
<key>UIBackgroundModes</key>
<array>
  <string>remote-notification</string>
</array>
```

### الخطوة 3: تشغيل التطبيق
```bash
npm run ios
```

---

## 🤖 Android

Badge على Android يعمل تلقائياً مع معظم اللانشرات الحديثة (Samsung, Xiaomi, OnePlus).

لا يحتاج إعداد إضافي!

---

## ✅ كيف يعمل؟

1. **عند وصول إشعار جديد:**
   - يظهر رقم أحمر على أيقونة التطبيق (iOS)
   - يظهر Badge على الجرس داخل التطبيق

2. **عند قراءة الإشعارات:**
   - يتم تحديث الرقم تلقائياً
   - عند قراءة جميع الإشعارات، يختفي Badge

3. **التحديث التلقائي:**
   - كل 30 ثانية يتم التحقق من الإشعارات الجديدة
   - عند فتح التطبيق يتم التحديث فوراً

---

## 🎯 الميزات الحالية:

✅ Badge على الجرس داخل التطبيق (يعمل الآن)
✅ عدد الإشعارات غير المقروءة
✅ تحديث تلقائي كل 30 ثانية
✅ Badge على أيقونة التطبيق (iOS - يحتاج تثبيت المكتبة)
