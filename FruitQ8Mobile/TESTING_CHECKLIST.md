## 🐛 في حالة فشل أي اختبار:

1. تحقق من logs:
   ```bash
   npx react-native log-android
   ```

2. تحقق من Firebase Console:
   - Storage: هل تم رفع الصور؟
   - Firestore: هل تم حفظ البيانات؟

3. تحقق من الصلاحيات:
   - إعدادات → التطبيقات → FruitQ8 → الصلاحيات

4. أعد بناء التطبيق:
   ```bash
   ./rebuild.sh
   ```
